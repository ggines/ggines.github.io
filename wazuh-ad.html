· 🛡 Bastionado de AD y monitorización 🛡 ·

Creación de un entorno basado en AD para auditar vulnerabilidades y aplicar medidas efectivas de defensa y mitigación

Descripción

En este proyecto, implementé un entorno basado en Active Directory para posteriormente auditar vulnerabilidades en el controlador de dominio
y aplicar medidas efectivas de defensa y mitigación.

🎯 Objetivos 🎯

Los objetivos fueron:

  • Desplegar un Windows Server con Active Directory, configurando el controlador de dominio.
  • Configurar un Windows 10 cliente para que pertenezca al controlador de dominio.
  • Instalar Wazuh Manager en Ubuntu Server para procesar los eventos de seguridad.
  • Instalar Wazuh Agent en los agentes para enviar los eventos de seguridad al Wazuh Manager.
  • Instalar Sysmon en Windows Server y el cliente y Suricata únicamente en Windows Server.
  • Lanzar ataques simulados desde Kali Linux hacia el Windows Server y el cliente.
  • Detectar y analizar los ataques en el Wazuh Manager.
  • Aplicar medidas de defensa y mitigación en el controlador de dominio.

💻 MVs utilizadas 💻

El entorno virtual se estructuró con las siguientes máquinas virtuales:

  • Windows Server 2022 Standard: Actúa como el controlador de dominio.
  • Ubuntu Server 24.04: Tiene instalado Wazuh Manager para recopilar los eventos de seguridad en tiempo real
    y Wazuh Dashboard para proporcionar la interfaz web.
  • Windows 10 Pro: Actúa como un cliente perteneciente al controlador de dominio.
  • Kali Linux: Actúa como atacante para lanzar ataques hacia el Windows Server.

🛠️ Herramientas usadas 🛠️

Para mejorar la detección de eventos, implementé estas herramientas:

  • Sysmon: Utilidad de Microsoft que permite detectar comandos, conexiones de red, o volcados de credenciales.
  • Suricata (IDS/IPS): Implementé Suricata para mejorar la detección de ataques de red.
    • Proofpoint Emerging Threats Rules: Además de usar las reglas por defecto de Suricata, añadí estas reglas dinámicas que se
      mantienen actualizadas en su sitio web para cubrir nuevas vulnerabilidades.

✔️ Conclusiones ✔️

Este proyecto me ha permitido entender el funcionamiento de un entorno basado en Active Directory,
conocer los vectores de ataque y vulnerabilidades presentes por defecto, y aplicar medidas de defensa y mitigación
para proteger el controlador de dominio y los equipos clientes.
